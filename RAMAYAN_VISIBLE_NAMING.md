# Ramayan Visible Naming Convention

This naming standard applies only to user-facing text. Internal code names, routes,
database columns, constants, PHP classes, JavaScript identifiers, and directory
names remain unchanged unless a separate migration is approved.

## Rules

1. Use names only where they improve understanding or reinforce the CMS identity.
2. Keep a generic technical term alongside a themed label when confusion is possible:
   `Patal Database`, `Brahmaand API`, `Sudarshana Security`.
3. Never rename a URL, CSS class, database table, PHP symbol, or API action as part
   of a visible-label change.
4. Use `Ramayan CMS` for the product brand; do not replace it with a character name.
5. Use place and role names consistently:
   Ayodhya for administration, Lanka for themes, Nandan for media, Patal for database,
   Vaanar for plugins, and Swayamvar for installation.
